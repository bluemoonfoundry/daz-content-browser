# pyproject.toml is the canonical dependency list.
#
# Quick dev install:
#   pip install -e ".[local_llm]"
#
# CPU-only torch (needed as a transitive dep of optimum[onnxruntime]):
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# Note: torch is NOT listed as a direct dependency. Install the CPU build
# above to avoid pulling in a large CUDA distribution.
#
# onnxruntime-directml provides GPU acceleration via DirectML (DirectX 12) on
# Windows, covering NVIDIA, AMD, and Intel GPUs. Falls back to CPU automatically
# if no compatible GPU is found. Not compatible with plain onnxruntime or
# onnxruntime-gpu — only one ORT package can be installed at a time.
#
# chromadb and optimum both pull in plain onnxruntime transitively, which shares
# onnxruntime-directml's import namespace and can silently win the install,
# leaving you on CPU with no error. install.py / `make install` force-reinstall
# onnxruntime-directml last to guarantee it stays active; if installing manually,
# run `pip install --no-deps --force-reinstall onnxruntime-directml` afterward.
# Check src/embedding_utils.py's startup log line for the actually active provider.
